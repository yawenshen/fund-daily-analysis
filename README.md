# Fund Daily Analysis Skill

面向 AI Agent 的基金每日复盘 Skill，结合大盘环境、行业主题走势、新闻事件与基金净值表现，对关注基金池给出条件化操作建议。

> 本项目提供基金复盘框架与操作分析方法，不构成投资建议，也不保证收益。所有建议均为条件情景，需根据实际市场变化动态调整。

## 核心能力

- 每日大盘环境复盘：指数表现、市场风格、成交情绪、关键事件
- 逐基金净值归因：昨日涨跌 vs 对应行业指数，跑赢/跑输分析
- 行业事件追踪：筛选与基金主题直接相关的新闻和政策
- 趋势位置判断：结合近1周/1月/3月走势判断当前位置
- 条件化操作建议：加仓 / 减仓 / 持有 / 观望 + 触发条件 + 仓位建议

## 分析流程

```
大盘环境复盘 → 逐基金分析（净值/归因/事件/位置） → 综合操作建议
```

### 第一步：大盘环境复盘

判断昨日整体市场环境：
- 沪深300、中证500、创业板指涨跌幅对比
- 市场风格偏向（大盘/小盘、成长/价值）
- 成交额与情绪变化
- 重要宏观事件和外围影响

### 第二步：逐基金分析

对 watchlist 中每只基金：
1. **净值表现**：昨日净值、日涨跌幅、各周期累计收益
2. **行业归因**：对比对应行业指数，分析跑赢/跑输原因
3. **事件催化**：筛选相关行业新闻，判断利好/利空
4. **趋势位置**：判断当前处于近期高位/中位/低位

### 第三步：综合操作建议

每只基金给出：
- 操作方向：加仓 / 减仓 / 持有 / 观望
- 触发条件：具体执行条件
- 仓位建议：比例范围参考
- 风险提示：需要关注的风险事件

## 数据与执行纪律

- 以最新已披露的官方净值为准，不使用盘中估算值
- 单日涨跌不直接定性为趋势反转，至少结合近1周走势判断
- 不把单一新闻事件作为唯一操作依据，需结合趋势位置
- 基金分析以中长期持有为前提，不鼓励频繁交易
- 若遇非交易日，提示"无新净值数据"并使用最近交易日数据
- QDII 基金净值延迟1-2个交易日，需单独标注最新净值日期
